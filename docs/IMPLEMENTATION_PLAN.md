# ExchangeTHB 简洁手机界面实施计划

目标：用户先选现金或加密资产，再选币种、金额，一次比较就能找到下一步。手机使用原生币种选择、数字键盘和至少 44px 的主要触控区域。

范围：现有首页、现金与加密比较页面、导航、语言选择、公共页壳、相关请求状态和数据标签。复用现有 API、后台、数据库与多语言。推广链接保留官方有效状态，不宣称暂停奖励。

基线：GitHub main `873beb68d200824fc5e66d29d57818d223474d82`，开发分支 `codex/mobile-simplification`。生产现场不修改，21 个未提交文件差异保存于本机临时审查文件，SHA256 为 `93006e5b0aa1746538dad821c53f173635ed860cbf24c5a55e4e1dd85fbbf766`。发布前必须逐文件复核，不能直接覆盖生产。

## 步骤

1. 核对版本、保留服务器差异，复用锁文件及受管运行时。
2. 把三套比较界面合成一个选择流程，首屏只显示必要输入；高级筛选与费用按需展开。
3. 结果突出预计所得与行动；最新结果和备用参考分开；编辑参数后不显示成上一组参数的结果。
4. 补齐错误、超时、空结果、定位拒绝、请求竞态与无效金额处理；保留买卖、查询预设及语言路径。

## 视觉与交互

白色纸面、深蓝文字、青蓝主按钮、浅蓝选择背景、琥珀参考数据提示。色值分别为 `#ffffff`、`#132b3a`、`#087f91`、`#e7f4f7`、`#a56816`，外围背景为 `#f3f7f9`。标题与正文使用系统无衬线字体，金额使用等宽数字。品牌特色是类似兑换单据的结果条：输入金额 → 预计 THB，省掉装饰性大横幅。

移动端为单列输入与结果，桌面为左输入右结果。首页只有一个主要比较工具；导航只保留现金、加密两项，语言在紧凑选择器中。详细说明放折叠区域，法律页保留在简短页脚。

## 验收

- 中英泰三种语言、现金和买卖方向、币种与小数金额都可用。
- 360px 和 390px 无水平溢出；选择与提交不依赖 hover。
- 首屏显示模式、币种、金额和比较按钮，不先滚过介绍或多张说明卡。
- 请求失败时明确给出重试入口；新的输入不会配上旧结果；较慢响应不会覆盖后来请求。
- 备用或过期数据不标成最新推荐；参考距离不标成用户实际距离。
- 现有测试不删除；构建和相关流程测试通过后交付。
